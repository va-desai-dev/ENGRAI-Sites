# Security Policy

> [!WARNING]
> This repository is used for public issue tracking, feature requests, and release notes. The source code for **ENGRAI** is proprietary and is not hosted here or anywhere publicly. This landing page serves as a documentation repository for ENGRAI on iOS and macOS. 

## Supported Versions
Security updates are only provided for the most recent version of **ENGRAI** available **ONLY through the App Store**. Please update to the latest release before submitting a report.

| Version | Installation Source | Supported |
| :--- | :--- | :---: |
| **v1.2.0** | App Store (incl. Mac) | **YES** |
| Current+ | TestFlight | *Beta ONLY* |
| Current+ | Alternate Stores | NO |
| Any Other Version | All Storefronts | NO |

## Reporting a Vulnerability
**Please do not report security vulnerabilities through public GitHub issues. Please do not report bugs or security concerns associated with the Beta program. Use the appropriate TestFlight beta reports accordingly.**

If you discover a security flaw in **ENGRAI** application, please report it privately using one of the following methods:

* **GitHub Private Vulnerability Reporting:** Click the **"Report a vulnerability"** button under the **Security** tab of this repository.
* **Email:** Contact us at **https://engrai.app/contact/** with the subject line `Vulnerability Report - ENGRAI`.

### What to Include
* A description of the vulnerability and its potential impact.
* Step-by-step instructions to reproduce the behavior in the App Store build.
* Your device model, OS version, and **ENGRAI's** version number.
* Relevant screenshots or crash logs (please redact any personal data).

## Disclosure & Patch Timeline
* **Acknowledgment:** You will receive a response within **48–72 hours**.
* **App Store Review Delay:** Because fixes for **ENGRAI** must go through the rigorous Apple's App Review process before reaching users, please refrain from publicly disclosing vulnerability details until the patched version is live on the App Store.

## Safe Harbor & Scope
We welcome good-faith security reports regarding the compiled App Store application (such as local data exposure, authentication flaws, or insecure network traffic). However, please note that decompiling, reverse engineering, or tampering with the proprietary binary remains subject to our [License](LICENSE.md) and Apple's Standard EULA.
